# RoomieMatch Cloudflare fixes — 2026-11-27

This update addresses the reported inbox/chat crash, conversation previews, profile-photo preview resilience, body-less save requests, and avoidable loading work.

## Changes

- `worker/people.js`: body-less `POST /api/people/:id/save` and `/block` no longer attempt to parse an empty JSON body. This fixes the reported `400 {"error":"Invalid request body."}` from the Save button.
- `worker/messages.js`: conversation list retrieval is bounded to the current user's latest 500 messages and only fetches connected users, rather than loading all users and every message then repeatedly scanning the complete list.
- `public/js/main.js`: inbox now has a conversation heading, count, search field, latest-message preview, timestamp and unread count. Chat rendering guards against stale async responses and detached DOM nodes, preventing `innerHTML` writes to null after route changes. The fallback polling interval is 10 seconds and pauses in background tabs.
- `public/js/main.js`: profile-photo preview is defensive, handles missing user/name/photo state, and removes a failed image while retaining the initials fallback. Cropper errors are caught cleanly.
- `public/js/components.js`: avatars use safe fallbacks and async/lazy image decoding.
- `public/css/styles.css`: compact scrollable inbox rail, message preview truncation, responsive chat behavior and profile-photo preview sizing.
- `public/index.html`: preconnects to Google Fonts to reduce font connection setup time.
- `public/js/main.js`: AI status is fetched once rather than on every badge refresh; badge refresh frequency reduced from 10 to 30 seconds.
